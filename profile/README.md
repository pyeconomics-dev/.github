# pyeconomics

Open economics and finance models for Python. Every model has typed inputs and
outputs, declared units, cited reference values it is tested against, and a
provenance manifest that lets any result be reproduced exactly.

- **Domains:** time value of money, fixed income, derivatives, equity and
  corporate finance, accounting, portfolio and performance, risk,
  econometrics and international finance.
- **One registry, every surface:** each model is written once, then served
  identically to Python and, as the roadmap lands, a command line, a REST
  API, an MCP server and a web app.
- **Licence:** Apache-2.0.

**Status:** 1.0 is in active development on `main`. `pip install pyeconomics`
installs 0.2.6, the current stable release.
